# External authority execution plan

This repository can prepare useful assets for authority building, but independent third-party references must be earned outside the codebase.

## Linkable assets already available

- Free browser-local PDF tools with transparent processing explanations.
- Practical PDF guides covering conversion, OCR, privacy, mobile workflows and file-size problems.
- A public technical explanation of browser-local processing.
- Legacy Microsoft Word 97–2003 DOC support with documented format behavior.
- Factual comparison pages that cite the official Adobe, Smallpdf and PDF24 sources rather than making unsupported rankings.

## Target categories

Build legitimate references from:

- software and web-app directories that accept useful tools;
- developer/open-source project listings;
- privacy-focused software resources;
- student and document-workflow resources;
- technology or productivity articles that independently review browser PDF tools;
- documentation or tutorials where the site's local-processing implementation is genuinely relevant.

## Outreach rule

Do not buy bulk backlinks, submit to spam networks, create fake reviews, or publish duplicated guest content. A useful third-party mention should point to the page that actually answers the reader's problem.

## Suggested outreach assets

Create short, evidence-based descriptions for:

- the PDF-to-Word workflow;
- the scanned-PDF OCR workflow;
- private/no-upload browser processing;
- old DOC 97–2003 conversion;
- mobile PDF workflows.

Keep descriptions factual and update them when the product changes.

## External tasks that require account/domain access

- connect a dedicated production domain and perform a controlled canonical/redirect migration;
- verify the site in Google Search Console;
- submit the production sitemap;
- list the product in third-party directories or request editorial mentions;
- review any directory's current policies before submitting.

Do not treat ranking gains from external references as guaranteed. Track the sources that actually produce impressions, clicks or referral traffic.
