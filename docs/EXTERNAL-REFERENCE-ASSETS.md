# FreePDF Tools — external reference assets

Use these factual descriptions for legitimate software directories, developer listings, privacy resources or editorial outreach. Do not paste them into bulk directory networks or duplicated guest posts.

## 1. PDF to Word

**Short description:** FreePDF Tools converts supported text-based PDFs into editable DOCX files in the browser. The workflow can optionally use local English OCR for pages that contain no selectable text.

**Long description:** FreePDF Tools provides a browser-local PDF-to-Word workflow for text-based PDFs, with an optional OCR fallback for image-only scanned pages. PDF text extraction and DOCX generation happen on the device for the supported workflow, so the source document does not need to be uploaded to an application conversion server. The output is designed for editable text and page structure; complex PDF layouts, tables, forms, fonts and OCR results should be reviewed after conversion.

**Reference page:** /tools/pdf-to-word

## 2. Scanned PDF OCR

**Short description:** Browser-local OCR for scanned PDF pages, producing recognized text and editable document output.

**Long description:** FreePDF Tools renders scanned PDF pages in the browser and uses a self-hosted OCR runtime to recognize visible text. It is designed for image-only documents where normal PDF text extraction cannot work. Recognition quality depends on scan resolution, contrast, orientation, columns, tables and character quality, so important names and numbers should always be checked against the source.

**Reference page:** /tools/ocr-pdf

## 3. Private PDF processing

**Short description:** Browser-local PDF processing for supported workflows without sending the selected document to an application conversion server.

**Long description:** FreePDF Tools separates website delivery from document processing. The browser still downloads public HTML, JavaScript and libraries, but supported PDF and document workflows process the selected file locally. The site documents the architecture and its limitations rather than claiming that ordinary hosting or network requests disappear.

**Reference page:** /guides/pdf-converter-without-upload

## 4. Legacy Word 97–2003

**Short description:** Convert supported Microsoft Word 97–2003 .doc files to PDF in the browser using a dedicated MS-DOC parser.

**Long description:** FreePDF Tools includes browser-based parsing for supported legacy Microsoft Word 97–2003 .doc files as well as modern DOCX-family documents. The original .doc format is parsed according to its internal structure rather than being treated as a renamed DOCX file. Older documents with unusual, damaged or encrypted content may still require manual handling.

**Reference page:** /tools/word-to-pdf

## 5. Mobile PDF workflows

**Short description:** Browser-based PDF workflows for phones, including JPG-to-PDF, PDF merging, splitting and organization.

**Long description:** FreePDF Tools provides mobile-friendly PDF workflows that run in the browser without requiring an installed desktop application. Mobile memory and file size still matter, so the guides explain practical ways to process large image-heavy or multi-page documents in smaller batches when necessary.

**Reference page:** /guides/merge-pdf-on-phone

## Evidence and link target guidance

When requesting a reference, point to the page that directly answers the reader's problem. Prefer a relevant tool or guide over the homepage.

Good reference contexts include:
- a software directory describing browser PDF utilities;
- a privacy-focused resource discussing local document processing;
- a developer resource that explains client-side PDF/OCR implementation;
- a productivity or document-workflow article comparing legitimate tools;
- a student or office workflow guide that needs a specific PDF operation.

Do not claim:
- that every PDF or document format is supported;
- that OCR is error-free;
- that the service has a server-free website;
- that FreePDF Tools is the "best" or "number one" converter;
- that a third-party site endorses FreePDF Tools unless it actually does.

## Submission checklist

Before submitting to any external site:
1. Check its current submission policy.
2. Use the exact supported feature set from the live product.
3. Link to the most relevant page.
4. Avoid duplicate copy across directories.
5. Keep a record of the referring URL and date.
