When this helps

Unlock a PDF when you have the password

This workflow is for files you are authorized to access. It does not bypass unknown passwords or remove protections you are not permitted to defeat.

Know the password

Enter the password associated with the PDF and generate a fresh copy without the encryption.

Keep the source intact

Save the original protected file separately, especially when it is signed, archived or part of a compliance record.

Check the result

Open the new PDF and verify that text, links, pages, forms and signatures still behave as expected.

Frequently asked questions

Can this unlock an unknown password?

No. The intended workflow requires a password you know. It is not a password-cracking service.

Are my PDF files uploaded?

The core operation is designed to run in your browser, so your selected PDF does not need to be uploaded to a conversion server.

Will signatures be preserved?

A newly generated PDF may invalidate digital signatures. Keep the original signed file and verify the new copy before relying on it.

What if the PDF has permission restrictions?

Encryption, permissions and signatures are different controls. Review the file and your authorization before changing its protection.
