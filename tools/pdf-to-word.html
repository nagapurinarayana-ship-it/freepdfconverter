What is preserved?

Selectable text and page order are carried into an editable DOCX. PDF page geometry, fonts, images and complex tables are not recreated exactly.

Scanned PDFs

This tool does not perform OCR. A scanned image-only PDF may produce little or no editable text.

PDF to Word conversion in your browser

The converter reads the PDF text layer with PDF.js and creates a standard DOCX package locally. The resulting document is editable in Microsoft Word and other compatible word processors.

Because PDF is a fixed-layout format, there is no universal one-to-one mapping back to Word. The converter prioritizes editable text and page boundaries rather than promising perfect visual reconstruction.

Privacy note: your selected PDF stays in this browser tab during conversion. The tool does not send the document to an application server.

Frequently asked questions

Can I convert scanned PDFs?

Not reliably. Image-only scans need OCR, which is not included in this local converter.

Will the Word file look exactly like the PDF?

No. The output focuses on editable text and page order. Complex positioning, images, forms and tables can change.

Does the conversion upload my PDF?

No. PDF.js reads the selected file inside the browser and the DOCX is generated locally.
