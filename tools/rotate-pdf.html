How to fix a sideways or upside-down PDF

Load your PDF and leave Rotate all pages selected when the whole document has the same orientation problem. If only part of the file is wrong, clear that option and enter the page range that needs rotation.

Rotations are added to the page's current rotation, so a page already rotated by 90° can be corrected with another 270° or adjusted again as needed.

Rotation tips

  • Use 90° clockwise for a page that needs a quarter turn to the right.
  • Use 180° for upside-down scans.
  • Use 270° clockwise for a quarter turn to the left.
  • Open the downloaded file before deleting your original document.

Frequently asked questions

Will rotation make text blurry?

No raster conversion is intentionally performed. Existing PDF page content remains PDF content.

Can I rotate just one page?

Yes. Clear Rotate all pages and set the same number in the From and To fields.

Is the PDF uploaded?

No. Rotation is applied locally in your browser.
