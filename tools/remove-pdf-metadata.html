What this PDF metadata remover changes

The tool deletes common entries from the PDF document-information dictionary and removes the catalog's document-level XMP metadata reference. Typical fields include a title, author name, subject, keywords, creating application, producing application and stored creation or modification dates. It saves the result as a new file while leaving your original untouched.

Metadata removal is a useful pre-sharing step, but it is not a forensic anonymity guarantee. A PDF may contain names or identifiers in visible page text, comments, form values, embedded files, images, fonts, digital signatures or application-specific objects. Inspect the cleaned result and use a specialist review process for high-risk publication.

Before you share a cleaned PDF

  • Open Document Properties in a separate PDF viewer and check the fields.
  • Search visible pages for names, email addresses and internal references.
  • Review comments, form fields, attachments and signature panels.
  • Do not use cropping or white rectangles as secure redaction.
Digital signatures: saving any changed copy can invalidate a signature. Preserve the signed original and use an approved workflow when signature validity matters.

Frequently asked questions

Does this remove the text visible on a page?

No. It removes standard metadata structures, not visible content. Page text must be reviewed separately.

Will the cleaned PDF be anonymous?

Not necessarily. The tool cannot promise removal of every identifier in every PDF object or embedded asset.

Is the file uploaded for inspection?

No. The browser parses and saves the PDF locally using the self-hosted PDF library.
