How to crop PDF edges

Select one PDF and enter how much to hide from each edge in millimetres. The same margins are applied to every page relative to its current crop box, so mixed page sizes remain mixed. Start with a small value such as 3–5 mm, save the copy and inspect pages that have content closest to an edge.

Cropping changes the visible page rectangle. It does not scale page content or permanently delete objects outside the new boundary. That makes cropping useful for presentation, printing and removing scanner borders, but unsuitable for concealing sensitive information.

Tips for a consistent result

  • Check portrait and landscape pages separately before applying one setting.
  • Leave extra space around punch holes, binding edges and printer marks.
  • Use smaller batches when different sections need different crop margins.
  • Keep the original so the full page can be recovered.

Frequently asked questions

Does cropping reduce image quality?

No intentional screenshot or image recompression is performed. The visible page boundary changes while the underlying page objects stay in the PDF.

Can I use cropping as redaction?

No. Hidden content may remain outside the crop box. Use a genuine redaction workflow for confidential information.

Can every page have a different crop?

This version applies one set of margins to every page. Split mixed sections and crop them separately when they need different settings.
