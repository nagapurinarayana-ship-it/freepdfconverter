Important

A target is a maximum goal. Some images cannot reach very small limits without becoming visibly poor, so the optimizer stops at its closest safe tested result instead of destroying detail just to hit a number.

Best format

JPG is usually the most practical choice for photographs. PNG is better when transparency or sharp flat graphics matter. WebP can be smaller when the receiving form accepts it.

Photo compressor for application upload limits

Use this tool when an application asks for a maximum image size such as 20KB, 50KB or 100KB. You can resize the image first, select an output format, and then let the optimizer search a bounded range of quality and dimensions.

Physical size: mm and cm

For forms that specify physical dimensions, choose millimetres or centimetres and select the requested DPI. The browser converts that physical measurement to pixels before encoding the image. Check the receiving application's exact specification because DPI and print size rules vary.

Batch processing

When several photographs need the same settings, select multiple files at once. Each image is processed independently and every result is downloaded as its own file. A per-file result list also shows the original size, output size, dimensions and whether the target was met.

How target compression works

  1. The browser reads each image locally.
  2. The selected dimension policy creates candidate output sizes.
  3. For JPG and WebP, the encoder searches quality values and then lower dimensions when necessary.
  4. PNG is resized without pretending that a lossy quality slider exists.
  5. The tool returns the highest-quality safe result that reaches the limit, or reports the closest tested result.
