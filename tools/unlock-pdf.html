What this free PDF unlocker does

The tool uses your known PDF password to read the encrypted document and writes a separate copy without PDF encryption. A blank password can work for a permissions-restricted PDF that already opens normally. It does not change your original file, upload either file or save the password.

The local engine supports common PDF standard password security. Certificate-protected documents, digital-rights-management systems and unusual security handlers may require the software that created the file. There is no paid tier or remote conversion quota; the 120 MB limit only protects browser memory.

Digital signatures: rewriting a signed PDF normally invalidates its existing signatures. Preserve the signed original and use an approved workflow when signature validity matters.

How to remove a known PDF password

  1. Choose the protected PDF.
  2. Enter its open password. If the PDF opens without a password but blocks editing, try leaving the field blank.
  3. Confirm that you are authorized to modify the document.
  4. Select Unlock PDF, then open the downloaded copy without entering a password.

Frequently asked questions

Can this recover a forgotten PDF password?

No. It does not attempt password guessing or recovery. You need the correct open password unless the PDF uses an empty user password for permissions only.

Are my PDF and password uploaded?

No. Both are passed directly to a WebAssembly worker in this browser. The worker is terminated after each attempt, and the site does not send document bytes or the password to an application server.

Why did the unlocked file lose its valid signature?

A PDF signature protects a particular byte sequence. Creating an unencrypted copy rewrites that sequence, so keep the original signed file as the authoritative record.
