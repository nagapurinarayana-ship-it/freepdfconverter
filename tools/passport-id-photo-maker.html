Before you submit

Photo rules differ by passport office, visa, exam, employer and application. Check the destination's current instructions for exact dimensions, background, head position, file format and file size.

Best input photo

Use a recent front-facing photo with even lighting and enough space around the head and shoulders. The crop tool cannot correct a photo that was captured too tightly.

Passport and ID photo sizing without uploading your photo

This tool converts a normal photo into a fixed JPG canvas using the dimensions you choose. For physical dimensions such as millimetres, the tool calculates the corresponding pixel canvas from the selected DPI. The receiving application is still the authority on what it accepts.

Why vertical framing matters

A standard center crop is not always the right crop for a portrait. Use the vertical framing slider to move the source image inside the fixed photo box before exporting.

Batch processing

When several photos need the same requirements, select them together. Each result is prepared independently and downloaded as its own JPG file.

Privacy

Processing happens locally in your browser. Your original photo is not sent to a conversion server by this tool.
