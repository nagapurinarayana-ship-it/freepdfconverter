    How to merge PDF files

    1. Select two or more PDF files.
    2. Use the up and down arrow buttons to arrange the files in the required order.
    3. Select Merge PDFs.
    4. The merged document downloads automatically.

    Why use browser-based PDF merging?

    This tool reads the selected documents through the browser's File API. It combines their pages in browser memory and creates the downloaded result without an application upload endpoint.

    This architecture also reduces server, storage and document-cleanup costs, helping the website remain free and easy to maintain.

    Frequently asked questions

    Can I merge password-protected PDFs?

    Password-protected or encrypted PDF files may not open. Remove the password using trusted software before merging them.

    Is there a PDF page limit?

    There is no fixed page-count limit in this page, but available device memory controls how much the browser can process. Smaller documents work more reliably on mobile devices.

    Does merging modify my original files?

    No. The original PDF files remain unchanged. The tool creates a new document named merged.pdf.

    Why is the merged file downloading automatically?

    Once processing is complete, the browser creates a temporary local download and saves the new PDF to your normal downloads folder.
