Target-size mode

Target mode renders pages at progressively smaller dimensions and JPEG quality, then rebuilds a PDF locally. It is designed for upload limits where reaching a maximum file size matters more than preserving selectable text.

Lossless mode

Lossless mode uses the existing qpdf WebAssembly engine for stream and object compression. It is the safer choice when you need to preserve the PDF's internal text and vector structure.

Compress PDF to 100KB, 200KB, 500KB or 1MB

Target-size compression is useful when an application, email system or upload form imposes a maximum file size. Select a target and the browser tries progressively lower image resolution and JPEG quality until it produces a PDF at or below the requested limit. Very complex or text-heavy PDFs may have a practical minimum size above the requested target.

Two compression modes

  • Lossless: preserves the original page content structure and focuses on PDF stream/object compression.
  • Target size: rebuilds pages as compressed images so the file can become substantially smaller. This can remove selectable text and vector structure, so use it when file size is the priority.

How it works

  1. Select your PDF. The file stays on your device.
  2. Choose a target or lossless mode.
  3. Compress locally. Target mode tries several quality/resolution combinations.
  4. Compare the result. The final file size and reduction are shown before download.

Frequently asked questions

Can I compress a PDF to 200KB?

Yes, select Target size and choose 200 KB. The tool attempts several local image-compression settings and reports the closest valid result. Some PDFs cannot be reduced below a practical minimum without extreme quality loss.

Will target-size compression keep selectable text?

Not necessarily. Target mode rebuilds pages from rendered images, so selectable text and vector objects can be lost. Use Lossless mode when preserving document structure is more important.

Are my PDF files uploaded?

No. The compression workflow runs in your browser. The selected document is processed locally on your device.

Why can't every PDF reach 100KB?

A PDF has a practical minimum size based on its page count and visual content. The tool does not keep degrading quality indefinitely just to hit an arbitrary number.

Can I compress a password-protected PDF?

Unlock the PDF first when you know the password, then compress the unencrypted copy.
