Signature image compressor for online forms

A signature upload usually has two separate constraints: a particular image shape or dimension and a maximum file size. This tool handles both while keeping the original file untouched.

Background cleanup

Near-white cleanup can make a photographed or scanned signature cleaner. It is conservative by design; inspect the prepared image so light strokes are not removed.

Batch signatures

Select several images with the same requirements and the tool processes them sequentially, then starts each result as an individual download.
