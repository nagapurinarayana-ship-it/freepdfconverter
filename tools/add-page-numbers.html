How to number PDF pages

Select a PDF, then choose the first and last PDF pages to change. If a five-page cover should stay unnumbered, enter 6 as the first PDF page and keep 1 as the first printed number. Choose a top or bottom position, adjust the type size and leave enough edge margin for a printer.

The number is drawn directly onto each selected PDF page. Existing content is not shifted to make room, so check that headers, footers, stamps and crop marks do not occupy the same area. Fix sideways pages with the Rotate PDF tool before numbering for the most predictable placement.

Practical numbering checks

  • Use 10–12 pt for ordinary A4 or Letter pages.
  • Test the longest number because it occupies the most width.
  • Use a larger margin when the PDF will be printed and bound.
  • Keep the original because numbering changes visible page content.

Frequently asked questions

Can numbering begin at a value other than 1?

Yes. Enter any whole number in Number to start with. The sequence increases by one on every page in the selected range.

Can I skip a cover page?

Yes. Set First PDF page to 2, or to the first body page, while leaving the printed starting number at 1.

Does the tool update a PDF page-label menu?

No. It draws visible numbers on pages; it does not rewrite the viewer's logical page-label tree or table of contents.
