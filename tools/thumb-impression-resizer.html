Privacy

Thumb-impression images are processed locally in your browser; the source file does not need to be uploaded.

Important

Thumb-impression rules differ by application. Treat the receiving form's current dimensions, file-size, background and format instructions as authoritative.

Why auto-trim helps

Large blank margins can make the actual impression tiny inside the output box. Trimming first gives the ink more useful image area.

When to use transparency

Transparent backgrounds are useful only when the receiving application supports them. White is the safer default when the instructions do not mention transparency.

Prepare thumb impressions without uploading the source image

Use the tool when an online form asks for a scanned or photographed thumb impression with strict file dimensions or a maximum upload size. Start with a square canvas or enter the exact dimensions specified by the form.

Trim before compressing

A tight crop usually makes better use of a fixed canvas than shrinking a large page photograph containing unused paper. Preview the cleaned result before submission so light ink has not been removed by background cleanup.

Target file size

The file-size setting is a maximum goal, not a guarantee that every image will land on an exact byte count. Simple black-on-white impressions usually compress more efficiently than noisy photographs or textured paper.
