Privacy

Thumb-impression images are processed locally in your browser; the source file does not need to be uploaded.

Practical starting point

240 × 240 pixels at 200 DPI and a 20–50 KB JPG is a common recruitment-form specification. The receiving form is authoritative.

Why auto-trim helps

Blank paper around a scan can make the actual impression tiny. Trimming first gives the ink more useful image area while keeping the output canvas exact.

Background

White is the safest default for ordinary form uploads. Use transparency only when the receiving application explicitly supports it.

Prepare thumb impressions without uploading the source image

Use the tool when an online form asks for a scanned or photographed thumb impression with strict dimensions or a maximum upload size. The 240 × 240 px / 200 DPI preset is a practical recruitment starting point, but the receiving form's current specification wins.

Trim before compressing

A tight crop usually makes better use of a fixed canvas than shrinking a page photograph containing unused paper. Preview the cleaned result before submission so light ink has not been removed.

Target file size

The file-size setting is a maximum goal. When an exact dimension cannot be compressed below the requested maximum without reducing dimensions, the tool preserves the required dimensions and tells you that the target could not be met.
