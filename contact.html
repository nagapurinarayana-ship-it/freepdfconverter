Questions, bugs or ideas?

FreePDF Tools is maintained as a public web project. The safest current contact route is the project's GitHub issue tracker.

Report a problem

When reporting a bug, describe which tool you used, your browser, what you expected and what happened. Do not attach private, confidential or sensitive PDFs to a public issue.

Open a GitHub issue

Feature suggestions

Suggestions are welcome when they fit the project's privacy-first, browser-local approach. The current focus is making the six core tools reliable, clear and fast rather than promising server-heavy features the site cannot perform well.

Privacy questions

Before contacting the project, please read the Privacy Policy, which explains local document processing, hosting requests, CDNs and future advertising.
